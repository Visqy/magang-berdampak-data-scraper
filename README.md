# Internship Data Scraper

This project is a Python-based tool to scrape and process internship vacancy data. It automates secure login using Selenium, collects embedded JSON data, and processes it into structured CSV files.

## 🔧 Features

- Secure `.env`-based credential login
- Selenium scraping of `data-page` JSON per internship detail page
- Cleaned and structured output with position, responsibilities, criteria, and partner information
- Ready for data analysis or integration
